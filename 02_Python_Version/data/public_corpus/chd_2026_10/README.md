## 采集方式
- 只采集无需登录的官网公开页面；校园门户（portal.chd.edu.cn）、"我在长大"等需统一身份认证的系统未访问。
- 教务处规章多为 PDF 附件，下载后提取文本再整理；HTML 页面去掉导航与页脚后整理。
- 不复制网页全文，按章节改写为与学生相关的要点；工作人员姓名、运营商营业员电话等与问答无关的个人信息未收录。
- 一个网页对应一份摘要，DCHD17 是例外：它合并了同系列的三个短页面，表格中列出全部原文。

## 批量采集脚本
`python -m src.ingestion.chd_crawler`（在 `02_Python_Version` 下运行）从各部门栏目列表页翻页采集公开政策，抽取正文或嵌入的 PDF（需 `pdftotext`，macOS 用 `brew install poppler` 安装），输出到 `data/public_corpus/chd_raw/`：每篇一个 `RAWxxxxxxxx.md`（loader 可直接读取，`content_type: raw_extract`），外加 `manifest.csv` 记录每个链接的处理结果（saved、filtered、duplicate、too_short、diagram 等）。可用 `--seed 列表页URL` 指定栏目、`--all` 关闭标题过滤；重复运行会跳过已处理的链接。

原文抽取包含官网全文，已在 `.gitignore` 中排除，也不会自动进入在线检索。要上线，先核对原文，再按本目录格式整理成 DCHD 释义摘要。

2026-10-08 的采集共保存 48 篇原文，其中 12 篇整理为 DCHD26–37，其余未上线，原因如下：
- 已有摘要覆盖的同一网页（选课、重修、考试、转专业、校园卡、医保简介等 20 篇）。
- 被新版替代的旧版本：2024 年版大学生医保政策简介（由 DCHD20 替代），2023–2025 级研究生落户须知（由 DCHD21 替代）；朋辈帮扶只保留最新一周的通知（DCHD37），其余 5 周不再单独入库。
- 主要面向教师、职工或学校管理部门：双语课程、校外实习基地、创新创业教育改革方案、消防隐患整改方案、校园固定电话、停车证、职工慢性病复审。

## 数据质量与隔离
- 信网处不同页面对南校区服务位置表述不一致（DCHD01 与 DCHD16/17），摘要保留冲突提示，不输出确定导航。
- 图书馆官网为前端动态渲染，开放时间、借阅规则等页面无法直接抓取；不采用搜索摘要中的旧时间作为现行规定。
- 学生处奖学金、困难补助评定办法，以及宿舍管理规定，在公开网站上未找到正式文本，本集暂缺，相关问题应明确未知。
- DCHD10（2013年）和 DCHD29（2006年）原文无具体日期，`source_date` 取文号年份；DCHD28 为 2016 年试行文件；DCHD24、DCHD36 的申请时间已过。
- 校医院两份页面对异地住院备案范围表述不同：DCHD30（2025-06）写省外住院需备案，DCHD20（2025-11）写西安市以外住院需备案。两份摘要都保留冲突提示，建议住院前电话确认。
- DCHD31–33 是校医院转载的全国或西安市通用医保政策，不是学校专门规定，摘要中已注明；DCHD32 不提供法律意见。
- 研究生规定不外推本科生；本科教务规章同样不外推研究生。
- 原12份模拟文档与用户上传属于 `simulation`，不混入官方范围。上海交大示例与其测评结果是历史实验，不进入在线检索。
- 每个会话只使用一种资料范围。切换时前端新建会话，后端拒绝跨范围复用；旧会话仍按模拟范围恢复。
