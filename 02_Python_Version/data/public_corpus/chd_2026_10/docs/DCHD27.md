# 长安大学完全学分制与弹性学制
## 适用对象
自2022级本科生起实行完全学分制，2022年9月开始实施；未来交通学院2020、2021级按其专门办法兼顾执行。
## 弹性学制
按学分注册、按学分毕业。四年制本科最短读3年、最长读6年，五年制专业最短4年、最长7年；在此期间修满培养方案最低学分即可毕业，毕业时学制仍按4年或5年计算。
## 学分与课程
培养方案总学分上限为：四年制理工类不超过170学分、其他类不超过160学分，五年制不超过210学分。课程分为通识教育、学科与专业、综合素质提升三大模块，其中至少4学分为面向全校的跨学院多元化课程。每学期修读15到35学分，可在一定条件下自主选课程、选教师、选上课时间，但须按课程先后修读关系选课。实践环节学分：人文社科类不低于15%，理工类不低于25%。
## 辅修与本研贯通
学校遴选部分专业开设辅修专业（约30学分）、辅修学士学位（约50学分）和微专业（10到15学分）。有条件的学院在第四学年开设研究生先修课程，考核合格且在长安大学读研的可直接认定学分。
## 收费方式
方案提出试行两部制收费，即按实际学习年限收专业学费，加上按所修学分收学分学费。具体标准以学校学分制收费管理办法和财务处通知为准，本摘要不提供金额。
