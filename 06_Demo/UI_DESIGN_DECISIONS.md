# UI Design Decisions

## 设计定位

面向课程答辩和公共服务演示，强调可信、易读和可解释。页面不采用AI紫色渐变、装饰动画或无意义卡片。

## 设计系统

- 页面类型：校园公共服务产品界面。
- 视觉参数：`DESIGN_VARIANCE 4 / MOTION_INTENSITY 2 / VISUAL_DENSITY 6`。
- 配色：冷灰背景、深色文字、校园绿主色，深浅模式均维持同一色系。
- 字体：本地系统无衬线字体栈，不依赖外部网络字体。UI-Pro-Max初始推荐的儿童教育字体不符合本项目的本科课程与公共服务语境，因此仅采用其高对比和可访问性建议。
- 圆角：容器14px，输入与按钮10px，按功能层级固定。

## UX要点

- 表单有显式label，placeholder不代替label。
- 所有按钮支持键盘焦点，触摸高度不低于42px。
- 提供加载、错误、空状态和清空会话状态。
- 在375px宽度下左右两栏折叠为单栏，发送按钮不换行。
- 遵守`prefers-reduced-motion`，页面不使用自动动画。
- 右侧面板不是装饰性仪表盘，它展示真实路由、Tool、引用和Trace，用于课程验证。
