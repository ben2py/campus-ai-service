# 长安大学校园卡新办与虚拟卡
## 用途与初始密码
校园卡用于食堂、部分区域消费和门禁。新用户初始密码为身份证号码数字的后六位，含X的把X改为1。本助手不收集或核验校园卡密码。
## 本科生与研究生
统招新生信息同步后，在微信或支付宝搜索"长安大学校园卡"小程序登录即可使用虚拟卡；实体卡统一发放到各学院。
## 其他人员
非统招学生由所属管理部门把名单报校园卡管理中心，之后通过小程序登录并上传照片使用虚拟卡，需要实体卡可到管理中心现场办理。教职工和聘用人员流程类似，聘用人员需先由单位在门户在线上报。
## 办理地点与电话
南校区：北院教学主楼一楼西侧校园卡管理中心（图书馆对面）。北校区：东区9号公寓一楼校园卡管理中心，以及师生服务大厅13号窗口。咨询电话 62630078、62630098、62805236。
