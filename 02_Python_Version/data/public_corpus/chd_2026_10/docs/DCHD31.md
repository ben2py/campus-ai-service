# 医保电子凭证（医保码）使用说明
## 用途与通用性
医保码可用于就医购药、医保查询和费用结算，由国家医保信息平台统一生成，全国通用。激活医保码不影响社保卡继续使用，社保卡挂失或补卡期间医保码仍可使用。
## 开通与渠道
可通过"国家医保服务平台"APP、地方医保小程序、微信、支付宝或银行APP开通。在某一渠道激活后只能在该渠道出示，换渠道使用需在新渠道重新申领。绑定手机号可在国家医保服务平台APP的医保码页面底部修改。
## 异地就医
办理异地就医备案后，可在就医地支持医保码的定点医药机构扫码直接结算。定点医疗机构可在国家医保服务平台APP首页"定点医疗机构"中查询。
## 与学校的关系
在校医院就诊和办理大学生医保报销时，需要出示本人医保电子凭证，见DCHD20、DCHD30。
