# 长安大学本科生学业导师制度
## 学业导师做什么
学业导师是受聘的专任教师，负责指导本科生的学业规划、选课、学习方法、竞赛与创新创业、生涯规划和就业。对受到学业预警的学生，导师要帮助分析原因、制定重修计划。
## 如何分配
各学院在新生入学前完成导师选聘，采用教师自荐与学院指定结合，鼓励师生双向选择，也鼓励以宿舍为单位分配。导师可跨学院选聘，每位导师每个年级原则上指导不超过8名学生。
## 指导频率
导师原则上从入学到毕业全程指导，在学生选课前开展工作。每位学生每学期一对一指导不少于3次；受到学业预警的学生每月至少一对一指导1次。形式可以是面谈、邮件或网络沟通，也有讲座、集中答疑等集体活动。
## 更换导师
导师工作变动无法履职，或学生学籍异动（如转专业）需要调整的，提交申请，由学院审核后报教务处和学生工作部备案。具体操作以所在学院细则为准。
