# 长安大学基层就业学费补偿与助学贷款代偿（2026年）
## 申请对象与条件
面向2026届全日制应届本科毕业生和研究生；定向、委培及在校期间已免学费的不能申请。需在毕业当年自愿到中西部地区、艰苦边远地区或老工业基地的基层单位工作，服务期3年及以上，并同时满足工作时间、区域、地点和岗位四方面要求。
## 补偿标准
只能申请毕业时所在教育阶段，在学费补偿和助学贷款代偿中二选一，只针对学费，不含住宿费。本科生每年最高20000元，研究生每年最高25000元，实际学费或贷款本息低于上限的按实际金额，年限按国家规定学制计算。资金分三年发放，第二、三次需通过在职在岗认定。
## 申请流程
学生在中央高校基层就业资助管理系统（https://jcjy.xszz.edu.cn/）注册并提交申请和证明材料，2026年的截止时间为9月4日；尚未落实单位但有意向的毕业生需在截止前预申请，次年再复核。之后经学院、学校审核，以全国学生资助管理中心结果为准。注册手机号用于接收审核结果，三年内不建议更换。
## 咨询
先联系所在学院资助专干；学校学生资助中心电话 029-61105098。
