# 长安大学学生区上网套餐与网络自服务平台
## 登录与新生预注册
网络自服务平台地址 https://wlfw.chd.edu.cn/ ，账号为学号，密码与统一身份认证一致。新生需先在登录页点"预注册"、选学生入口完成身份验证，否则直接登录会提示密码错误。新生统一身份认证一般在8月10日后陆续激活。
## 开通校园网
新账户默认不能上网。登录后在"变更套餐"中选校园网套餐并提交，先缴开户费，再缴套餐使用费，状态变为正常即可上网。校园网资费为每月12元或半年60元，带宽约10Mbps，可同时登录三台设备。
## 运营商套餐
宿舍区也可选联通、电信的单宽带套餐，按月或按年计费；或选运营商融合套餐（买指定手机套餐并绑定学号）。融合套餐只能在平台预选，开户费和套餐费需到对应运营商营业厅缴纳。具体带宽和价格以平台和营业厅为准。
## 注意事项与线下地点
本周期内变更套餐，要到下个周期才生效。遇到问题拨打 82334701，或到南校区北院教学主楼西侧网络运维服务中心、北校区修远三区教学楼3101办理。
