# 长安大学校园视频监控查看申请
## 适用情形
个人财物丢失、遗失，或其他不涉及他人隐私的事项，可以申请查看校园监控。涉及治安、刑事案件或他人隐私的，需要先向公安机关报案，由民警经保卫处同意后调阅。
## 申请步骤
1. 从保卫处网站"服务指南"下的"下载专区"下载《长安大学校园视频监控查看申请表》，填写后打印。
2. 在校学生的申请表需由辅导员和学院负责人签字，并加盖学院公章。
3. 持申请表找保卫处治安科（或值班干部）签字同意后，由监控室值班人员查看。
## 注意
查看会登记在案。只有公安机关因办案需要才能拷贝、复制录像，其他人员不得拍照或录像。保卫处电话见DCHD23。
