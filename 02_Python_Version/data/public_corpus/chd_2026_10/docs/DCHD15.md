# 长安大学毕业证明书与学位证明书补办
## 适用情形
学校颁发的普通本专科毕业证书或本科学士学位证书遗失、损毁后，可申请毕业证明书和学士学位证明书，证明书与原证书具有同等效力。
## 第一步：线上申请
将填好的申请表扫描件、本人身份证扫描件、蓝底二寸免冠电子照（480×640，40KB以内，JPG）以及毕业证、学位证扫描件（如有）发到学籍学历邮箱 xjxl@chd.edu.cn。教务处依据档案核实，属实的会通知提交后续材料，不属实的说明原因并不予办理。
## 第二步：线下办理
审查通过后，本人在工作日（寒暑假除外）携带签名纸质申请表、身份证复印件、两张蓝底二寸照片、原证书复印件（如有），以及从学校档案馆调取的毕业生名单和授予学位人员名单（2001年以后毕业的不需学位名单；档案馆电话 029-82334084），到渭水校区北辰楼305办公室办理。委托他人需书面委托书和双方身份证复印件。
## 办理时间与咨询
证明书信息原则上与原证书一致，一般在提交纸质材料后一个月内完成，届时通知领取。咨询电话 029-61105239。
