# 长安大学推荐免试攻读研究生（推免）条件
## 基本条件
面向纳入国家普通本科招生计划的应届毕业生，不含专升本、第二学士学位和独立学院学生。要求品德良好、无考试作弊和学术不端记录、无违纪处分，德育实践成绩良好以上，身体达到体质健康标准。
## 成绩与外语
前6个学期（五年制前8个学期）学业成绩（不含通识任选课）在本专业或方向前35%，前3年（五年制前4年）不及格不超过1门次且补考或重修合格；排名按首次修读成绩计算。非英语专业需英语四级425分以上，或托福65分以上、雅思5分以上；英语和日语专业需通过专业四级。
## 综合排名
综合排名为学业成绩加综合素质测评成绩。学业成绩为前3年课程成绩按学分加权平均；综合素质测评由学院评定，总分不超过5分，涵盖社会服务、科研、竞赛、文体等。全国重大学科赛事获最高奖第一名的可加5分。退役复学学生经申请审核学业成绩加2分，符合特定立功条件的有专门推荐政策。
## 程序与申诉
学院公布本院细则和名额，学生向学院提交申请表和证明材料；科研成果和竞赛获奖需答辩审核，拟推荐名单在学院网站公示不少于3天，再经学校审定公示，推免生在全国推免服务系统填报志愿。对结果有异议可先向学院推免工作小组反映，再向学校推免遴选领导小组申诉。弄虚作假者取消资格。
