# 长安大学本科生转专业与专业分流
## 申请条件
转专业面向全日制本科一年级在读学生，在校期间只允许转一次。需注册手续齐备、缴清学费、未受过纪律处分，并对转入专业的课程、奖学金和就业情况有明确认识。艺术类等特殊招生类型，或录取前已约定不能转专业的学生不在范围内。退役复学学生可自主选择转入专业，不占指标。
## 接收人数与考核
各专业接收转入人数以学校批复计划为准，原则上为该专业现有学生数的10%到20%。各学院公布本院细则，写明选拔条件、人数、考核方式和评分标准；考核综合成绩中第一学期加权学业成绩占比不低于70%。
## 时间与流程
转专业在一年级春季学期启动。学生在规定时间内向所在学院提交书面申请表，并在教务系统提交申请；所在学院审核资格，接收学院考核录取，教务处审核后报学校领导小组审议，名单在校园门户公示不少于3天。逾期视为放弃；公示结束前可向接收学院申请撤销，被接收后不得转回。学籍变更在秋季学期开学时生效，转出前需完成本学期原专业课程。
## 专业分流与学分认定
按大类招生的学生入校1到2年后进行专业分流，依据学生意愿、成绩排名和专业资源综合确定，分流后班级不超过40人。转入后按新专业培养方案培养，原专业已修课程由接收学院认定：学分不低于新专业同名课程的继续有效，不在新方案中的可认定为多元化课程学分。
