# 长安大学校园卡挂失、充值与密码重置
## 挂失与补办
线上：在"长安大学校园卡"微信或支付宝小程序绑定校园卡后，用"卡挂失"功能立即挂失，再到校园卡管理中心办理新卡。线下：持本人身份证到校园卡管理中心直接挂失、补办。
## 充值
推荐在小程序中使用"校园卡充值"在线充值；也可以到南、北校区校园卡管理中心线下充值。
## 密码重置
线上：在小程序绑定校园卡后，用"密码修改"功能重置。线下：持本人身份证到校园卡管理中心办理。
## 地点与电话
南校区北院教学主楼一楼西侧（图书馆对面）；北校区东区9号公寓一楼，及师生服务大厅13号窗口。电话 62630078、62630098、62805236。
