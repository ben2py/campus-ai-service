# 长安大学校外人员与车辆入校报备
## 访客入校
校外人员进校需由校内教职工代为报备。报备后访客手机会收到含入校二维码的短信，入校时打开二维码，由门岗校卫队员扫码查验后进入。原文只写明由教职工报备，未说明学生能否直接为亲友报备。
## 车辆入校
已报备车辆自动抬杆进校，不再人工核验；校内违停、超速的车辆会收到短信提醒。

北校区 61105110；南校区南、北院 82338110；南校区东、西院 82339110。
