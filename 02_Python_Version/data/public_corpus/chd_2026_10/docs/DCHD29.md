# 长安大学校外实习实践安全纪律
## 适用范围
适用于学校在校外组织的教学实习、生产实习、毕业实习和教学调查。带队教师是实习队安全第一责任人；实习前学院会进行安全动员，学生须与学校签订《实习安全责任书》，未签订的可被拒绝参加实习。
## 学生纪律
遵守实习队规定和当地法规风俗；外出必须向带队教师请假，不得私自外出，到陌生环境要报告并结伴同行。野外实习须由教师带领，着装符合安全要求，不得单独活动。严禁到江河湖海、水库游泳，严禁打架斗殴、床上吸烟和不规范用电，不得私自组织参观、野炊、旅游等活动。使用未操作过的设备前先读懂说明。原文还对女生单独或夜间外出有限制性规定。
## 突发情况
走失时及时通过电话联系带队教师、同学或拨打110；遇到危急情况可直接拨打119、110、120，并说明具体地点和现场情况，之后听从带队教师统一指挥。
## 违规后果
违反规定的，按学生违纪处分规定给予纪律处分，触犯法律的依法承担责任。
