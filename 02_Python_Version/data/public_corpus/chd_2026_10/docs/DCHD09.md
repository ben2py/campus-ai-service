# 长安大学本科生考试规则与成绩复核
## 考试种类与补考时间
考试分期末考试、补考、结业生返校补考和其他考试。期末不及格课程的补考一般安排在下学期开学初；毕业班最后一学期的不及格课程补考在当学期末进行。结业生返校补考一般在每年四月中旬。所有考试在本科教务系统中安排，由学院通知学生。理论课考试一般为120分钟。
## 考场规则
考生凭有效证件提前10分钟进场，迟到15分钟不得入场，开考30分钟后才能交卷离场。按考号隔位就座，证件放在桌面右上角。除考试要求外不得携带文字资料和通讯工具，书包资料集中存放，不得互借计算器。考试结束信号后立即停笔，不得把考试材料带出考场。对监考有意见应在考后通过学院或教务处反映。
## 平时考核不足
缺交作业、实验报告等平时考核内容累计达全学期总量三分之一的，不得参加该课程期末考试，成绩按零分计。
## 成绩查卷
对成绩有疑问，可在成绩公布后的新学期初前两周内，经学院分管教学的副院长批准，由学院教务人员统一向教务处申请查卷，同一门课程只能申请一次。开课单位一周内组织非主讲教师复核，教务处收到结果后三天内经学院反馈给学生。
