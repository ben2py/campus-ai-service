# 长安大学学生创业实践资助与创客空间
## 谁可以申请
长安大学全日制在校本科生、研究生，或毕业未满两年的校友组成的创业团队。团队无不良信用和违纪违法记录。
## 创业实践专项资助
面向已开始运营、具备办公司条件，并在"挑战杯""互联网+"、大创计划等竞赛中获得较高荣誉的项目，需1到2名指导教师或创业导师推荐。提交创业计划书、项目证明、知识产权证书、财务流水等材料，集中评审。资助一般每项2万元，最高不超过10万元；批准后先拨60%，中期检查通过后再拨40%。经费可用于注册公司、知识产权申请、设备（不超过总额30%）、孵化器工位（不超过30%）及必要的交通、办公、宣传费用，团队需按季度和年度提交运营报告。
## 创客空间
创客空间常年受理、集中评审，入驻条件与上面类似，并要求有校内在职教师作指导。入驻团队可获得约1年的免费工位，以及政策、法律、专利咨询和创业导师等服务；每季度末提交进展报告，入驻两年仍达不到孵化标准的需退出。
## 孵化器
在创客空间培育后、已取得工商税务注册的团队，可申请进入创业孵化器正式运营，经专家评审后签署场地协议并缴纳入园保证金。
