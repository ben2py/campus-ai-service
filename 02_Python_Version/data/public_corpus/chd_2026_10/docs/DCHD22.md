# 长安大学教学区电动自行车管理
## 适用范围
适用于北校区教学区和南校区北院、东院、西院教学区内电动自行车的登记、行驶、停放和充电。
## 登记通行
电动自行车需先在地方交管部门上牌，再办理学校"校园通行标识牌"并贴在指定位置，两者缺一不能进入教学区，每人限办一张。办理时需签安全行驶承诺书，提供审批单、电子行驶证、本人学生证或实体校园卡，现场拍照核对车辆。校外人员临时进校的车辆由校内对接单位在门户"一网通办"报备。
## 行驶与充电
靠右顺向行驶，必须戴头盔，时速不超过20公里。严禁电动车和电池进入宿舍或其他建筑物内充电，严禁飞线、私拉电线充电，应使用校园充电桩，充完及时挪车。
## 停放
在划定区域停放，不得停在消防通道、人行道、草坪、门厅、楼梯间、安全出口等处，禁止推入电梯。长期不用或无牌车辆经公示后统一清理。
## 违规处理
超速、不戴头盔、违规载人、逆行、看手机或戴耳机骑行、从事载客外卖、乱停等属于违规。每年（9月9日至次年8月31日）违规3次及以下短信提醒，4到6次书面提醒，7到9次校内通报，累计10次及以上或发生较大事故的一年内禁止在教学区行驶。违规充电按消防规定和学生违纪处分规定处理。
