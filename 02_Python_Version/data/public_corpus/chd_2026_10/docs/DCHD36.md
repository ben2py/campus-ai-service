# 基层就业学费补偿：毕业后的在职在岗确认
## 为什么要确认
获得基层就业学费补偿或助学贷款代偿资格的毕业生，资金分三年发放；第二、三次发放前需要在系统中确认仍在基层岗位。
## 怎么填报
登录中央高校基层就业资助管理系统 https://jcjy.xszz.edu.cn/ ，在"第一次在职在岗确认"或"第二次在职在岗确认"模块填报（2025年通知中，2024届做第一次、2023届做第二次）。正常在岗选"在岗"；原单位内部调动选"换岗（原单位内部调动）"；辞职后入职新单位选"换岗（到新单位就业）"，新单位仍需符合审核标准并重新上传材料，且前后就业时间必须连续；已离开基层岗位的选"离岗"。
## 时间与审核
2025年学生填报截止为8月28日，之后经学院、学校审核，以中央审核结果为准；逾期不受理，弄虚作假将追责。
## 咨询
先联系所在学院资助专干；学生资助中心电话 029-61105098，办公地点为北校区北辰楼404。
