# 长安大学新生入学落户须知（2026级）
## 是否迁户口
新生（本科、研究生）可按自身需要自愿选择是否把户籍迁入学校集体户。西安市户籍新生的户口一律不迁入学校。
## 落户地址
按入学后实际住宿校区填写。南校区北院、西院：雁塔区小寨路派出所，地址为西安市雁塔区长安中路33号长安大学。南校区东院：雁塔区育才路派出所，地址为雁塔区雁塔路南段4号附2026号。北校区（渭水校区）：未央区汉城派出所，地址为未央区尚苑路1号。
## 注意事项
按西安市新政策，新生只能在当年入学报到时统一落户，其他时间不再办理。已办迁移证的户口已从原籍迁出，若临时决定不落户，要尽快迁回原籍。具体流程开学后关注信息门户或"平安长大"微信公众号。
