# 双 Prompt 五题实验

## 目的

比较“直接回答”与“严格依据证据、无证据拒答并附来源”两种系统提示词对答案忠实度和引用完整性的影响。

## Prompt

- Prompt A：`根据上下文直接回答。`
- Prompt B：`仅使用上下文；证据不足时拒答；回答末尾附来源。`

## 固定问题

1. 图书馆周末几点开馆？
2. 本科生最多能借几本书，借期多久？
3. 申请国家励志奖学金需要什么额外条件？
4. 突发情况没参加考试，缓考材料多久内补交？
5. 宿舍楼晚上几点关门？

## 运行

只有在本人已将密钥写入被 Git 忽略的 `.env` 后运行：

```bash
python -m src.evaluation.prompt_runner
```

结果写入 `../04_Evaluation/prompt_experiment.json`。未配置密钥时脚本会退出，不会发起请求或制造模拟结果。当前仓库中的该 JSON 明确记录为未运行状态。
