# 长安大学本科生学业预警与帮扶
## 预警性质
学业预警是对可能延长学习年限、试读、退学、不能毕业或不能获得学位的提前提醒，不属于纪律处分，不记入档案。学院会向学生下达预警通知单并告知家长。
## 五类预警
课程预警：学期中根据考勤和期中考核，对公共基础课学习困难者预警。学分预警：学期初对上一学期不及格必修课（含缺考）累计超过8学分者预警。退学或试读预警：秋季学期初对累计所得学分比应得学分少12学分及以上者预警。结业或延长学习年限预警：针对未完成计划课程的毕业年级学生。学位预警：毕业年级学生有20学分靠补考或重修获得、因作弊或学术不端受留校察看、非外语专业未通过英语四级、或保留学籍试读后恢复学籍之一的，给予学位预警。
## 不纳入预警
休学期间、合作项目交流期间和服兵役期间的学生不纳入预警。
## 帮扶措施
学院按"一人一档一策"跟踪，包括学业规划和重修计划指导、课程辅导班或学习小组、定期跟踪和家校沟通。学生工作部依托"一站式"学生社区设学业辅导室，提供线上预约、线下辅导；心理健康教育与咨询中心提供心理帮扶。
