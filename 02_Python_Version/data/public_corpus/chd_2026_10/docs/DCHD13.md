# 长安大学学士学位授予条件（2025版）
## 授予条件
本科毕业生完成教学计划规定任务，课程学习和毕业论文（设计）成绩合格，经审核准予毕业的，可申请相应学科门类学士学位。还要求遵守法律法规和学术规范。
## 不授予的情形
在校期间受到刑事处罚，或因考试作弊、学术不端受到留校察看处分的，不授予学士学位。
## 受处分后的申请途径
因作弊或学术不端受留校察看处分、但毕业前撤销处分且满足下列之一的，可本人申请，由学院学位评定分委员会同意后报学校审定：课程总评成绩在本专业前25%；在学校认可的学科竞赛榜单项目中获省级及以上奖励（名次要求按奖项等级区分）；以第一作者在《长安大学学术期刊目录》内发表与专业相关的论文；以第一作者获批国家发明专利。
## 办理程序
毕业生在规定时间内填写学士学位申请表，学院学位评定分委员会审查后报教务处，经学校学位评定委员会终审后授予。
## 新旧版本
本细则自2025年6月印发起施行。2021级及以前学生，原长大研〔2021〕175号细则中除第十条第三款外继续适用；该款涉及的具体内容本摘要未收录，需向教务处核实。
