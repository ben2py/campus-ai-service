# Coze Version

此目录保存Coze搭建规格、待上传知识文档、运行日志和截图清单。

当前环境未提供Coze账号或工作空间，因此没有伪造Bot、Workflow、耗时、截图或日志。完成在线搭建后，请按`screenshots/README.md`保存证据，并回填`../04_Evaluation/three_track_comparison.csv`中的Coze字段。

## 搭建顺序

1. 上传`knowledge/`的12份Markdown资料。
2. 按`workflow/coze_build_spec.md`创建Bot、Knowledge Search、LLM、Tool、Memory与Unknown分支。
3. 使用`../04_Evaluation/evaluation_v1.json`中20题运行测试，至少完成指导书要求的10题。
4. 导出或截图保存日志。
