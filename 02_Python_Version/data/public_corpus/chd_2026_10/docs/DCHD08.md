# 长安大学本科生课程重修与补修
## 什么情况需要重修
课程不及格的，下学期初有一次补考机会；补考仍不及格、未办缓考擅自缺考、无故缺课累计达总学时三分之一及以上、因严重违纪或作弊被取消考试资格的，需要重修该课程。
## 重修次数上限
在最长学习年限内，重修课程门数不限，但每门课程重修最多3次。最长学习年限为标准学制再加不超过两年。
## 补修
因转学、转专业、学籍异动或交流学分不满足要求等原因缺修培养方案课程的，需要补修，最长学习年限内可申请补修1次。补修课程考核未通过，可参加补考或申请重修。
## 重修方式与申请
重修一般在下一学年对应学期完成，可插班随下一年级上课，或与本人课表冲突时申请跟班重修（冲突时段可不随堂）。学期初按信息门户的重补修通知在本科教务系统选课；补修选课需经教师、学院和教务处审核。未办理手续的，考核成绩无效。重修与课表冲突且申请人数超过20人时，可能在周末或晚上单独开班。
## 考核与成绩
重修课程须参加考核，合格后取得学分，按实际成绩记载。重修课程考试与其他考试冲突时，其他课程可办理缓考，重修课程本身不予缓考和补考。
