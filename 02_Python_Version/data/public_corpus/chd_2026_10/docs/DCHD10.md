# 长安大学考试违纪与作弊的成绩认定
## 考试违纪
不服从考场安排的行为认定为违纪，例如携带规定外物品或未放在指定位置、不在规定座位、开考前或结束后答题、旁窥或交头接耳、擅自离场、把试卷带出考场、在规定外位置写姓名或做标记等。违纪者取消该场考试资格，该科成绩无效。
## 考试作弊
携带与考试相关的资料或存有相关内容的电子设备、抄袭或协助抄袭、携带可收发信息的设备、传接物品或交换试卷、评卷时发现答案雷同等，认定为作弊。作弊者该课程成绩无效并取消补考资格，只能重修，所欠学分计入学籍处理学分。
## 严重作弊
替考或被替考、组织团伙作弊、利用通讯设备传输作弊、在校期间两次及以上作弊等严重情形，本学年已修课程成绩和学分全部清零并降级处理。
## 处理程序
监考教师填写考场和作弊登记表并移交物证，教务处一般在两个工作日内作出成绩认定和学籍处理并公布；纪律处分另由学生工作部按规定认定。
