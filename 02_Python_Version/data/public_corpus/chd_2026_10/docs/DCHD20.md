# 长安大学大学生医保参保与报销
## 参保
全日制本科生和研究生（含港澳台学生）可参加西安市大学生基本医疗保险，属于城乡居民医保，不是商业保险。按自然年度缴费，由学校医保办统一办理，费用由学生个人承担，缴费时间关注校医院网站和信息门户通知。
## 待遇等待期
自2025年起，未在集中参保期参保或未连续参保的，设3个月固定等待期，每多断保一年再加1个月，等待期内费用不报销。连续参保的老生，待遇期为下一年度1月1日至12月31日。
## 门诊报销
在校医院挂号时出示身份证或校园卡及医保电子凭证，可直接报销。确需外转的，由校医院开转诊单，转诊单一周内有效，急诊抢救不需转诊单；外转和寒暑假、实习、休学期间异地门诊的费用先垫付，保留票据，在"长安大学医院"微信小程序预约报销。未按规定转诊的不予报销。
## 门诊报销比例与限额
门诊费用在医保范围内的报销比例是70%，一个医保年度门诊最高报销500元，校医院门诊、外转门诊和异地门诊合并计算。
## 住院报销
西安市内定点医院住院，入院时在医保窗口登记，出院直接结算。去西安以外住院前务必办理异地就医备案（可用陕西医保、国家医保服务平台等APP），并使用医保电子凭证；未备案的非急救住院报销比例降低20个百分点。统筹支付：一级医院起付150元报80%，二级400元报70%，三级1200元报60%，三级特等2000元报50%，门诊和住院统筹年度合计最高20万元。零星报销材料最晚在出院后6个月内交校医院医保办，审核周期约4到6个月。同时有商业保险的，先走大学生医保。
