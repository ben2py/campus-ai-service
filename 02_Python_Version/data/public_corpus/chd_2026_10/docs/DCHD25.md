# 长安大学室外场地使用申请
## 线上申请
从学校官网进入"校园门户"，登录后在搜索栏输入"室外"，选择"室外场地申请（二级单位、学院）"，填写活动信息后提交。原文入口面向二级单位和学院，学生社团或班级活动一般需经所在学院或指导单位发起。
## 审批与留存
提交后由所在单位（学院）签署意见，再由保卫处审批，全程网上完成。审批通过后打印申请表，在活动现场留存备查，不需要线下盖章。
