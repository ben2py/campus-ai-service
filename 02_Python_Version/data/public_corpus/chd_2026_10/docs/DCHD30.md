# 长安大学大学生医保门诊报销预约流程
## 门诊就医
在校医院缴费时主动出示个人医保电子凭证，可直接报销。确需外转的，由校医院开具转诊单，一周内有效，急诊抢救不需要转诊单。寒暑假、实习或休学期间在外地就医的，该指南建议优先选择二级及以下医保定点机构，无需转诊单。
## 报销材料
转诊单（校医院就诊不需要）；门诊发票或打印的电子发票一式两份；门诊病历、检查报告、收费清单和处方。现场携带的材料须与线上提交的一致。
## 预约流程
1. 在"长安大学医院"微信小程序提交报销材料，等待审核。
2. 审核通过后，在小程序里选择报销时间。
3. 按预约时间带材料到大学生医保办录入并确认报销金额。
4. 本人签字确认。
## 骨折门诊
该指南所列部分西安市定点医院已开通大学生门诊骨折直接挂账，可在医院直接结算。
## 住院备案说明
该指南写明省内住院不需要办理异地就医备案、省外住院需提前备案（备案类型选"临时跨省外出就医人员"，备案时间要早于入院）。较新的DCHD20则写为西安市以外住院需备案。两者不一致，住院前请先向医保办电话确认：南校区 029-62630020，北校区 029-61105807。
