# 长安大学公共基础课朋辈学业帮扶
## 是什么
学工部组织"星光伴学"朋辈学业帮扶，由成绩优秀的学生志愿者为其他同学辅导数学、力学、制图、物理等公共基础课，形式包括重点知识串讲、习题答疑和一对一辅导，面向全体学生开放，补考、缓考学生是重点帮扶对象。2025-2026学年秋季学期共开展约970场。
## 怎么查场次
每周的辅导安排（时间、地点、课程）发布在"我在长大"智慧学工系统的"朋辈帮扶"模块，学院也会转发通知。例如2026年春季学期第2周安排了61场，结合补考、缓考时间开展。
## 想当志愿者
授课学生志愿者需通过学校的招募通知报名，辅导结束后在"我在长大"系统"朋辈帮扶"模块提交完成情况。具体招募时间关注学工部通知或咨询所在学院。
