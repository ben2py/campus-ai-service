# 医保卡合规使用与违规后果
## 不能做的事
医保卡或医保码必须本人实名就医购药，不得借给亲友冒名使用。不得把医保卡留在医疗机构，警惕以减免费用、赠送礼品等方式诱导住院或开药的机构。不得转卖用医保开出的药品，或接受返现、实物。在多地都有参保的，同一笔费用只能在一个地方报销。
## 不能用医保报销的费用
应由工伤保险支付的费用、依法应由第三方承担的费用（如打架受伤、有责任方的交通事故），以及在境外就医的费用，都不属于基本医保支付范围，隐瞒事实使用医保基金属于违法。
## 违规后果
违规报销的金额会被追回；视情况暂停医保联网结算3到12个月，期间看病需先垫付再手工报销；故意骗取的处骗取金额2到5倍罚款；金额达到一定标准的移送司法机关，可能构成诈骗犯罪。具体认定由医保部门和司法机关作出。
