# 西安市门诊慢性病认定与报销
## 适用对象
参加西安市基本医疗保险的城镇职工和城乡居民。大学生医保属于城乡居民医保，患有规定病种慢性病的学生可以申请。
## 如何认定
在西安市二级及以上定点医院住院的，出院结算时在该院医保办领取并填写门诊慢性病申请鉴定表，由两名相关专业医师（至少一名副主任医师）鉴定，一般不超过20个工作日完成认定。使用异地住院资料，或甲亢、甲减、阿尔茨海默病等少数可凭门诊病历申请的病种，需向参保所属医保经办机构申报；城乡居民经社区提交。认定结果可在定点医院医保办或陕西医保公共服务平台查询。
## 待遇与复审
认定通过的次月起享受门诊慢性病待遇。部分病种需要复审，在待遇期满前三个月内申请，通过后享受期为2年。
## 报销比例
在慢性病定点医院或凭外配处方在定点药店，与认定病种相关的费用可直接结算。年度个人支付达到起付线700元后，超出部分统筹基金支付70%（大骨节病等少数病种起付线为零）。每月统筹支付有限额，单次处方用药最长不超过三个月。因急诊、异地等原因未直接结算的，次年1月1日至3月31日集中申报报销。
