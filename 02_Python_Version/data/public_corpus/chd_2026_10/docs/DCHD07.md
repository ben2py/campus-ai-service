# 长安大学本科生选课与修课规定
## 每学期学分
学校实行弹性学制和选课制。每学期修读学分一般在15到35学分之间；超过35学分（含辅修超过45学分）需学业导师同意、学院审核并报教务处批准。选课时先保证本专业培养方案的必修课，有先后修读关系的课程应先修前序课程。
## 选课方式与意愿值
选课方式有三种：直选（先到先得）、抽签（不分先后，按课容量抽签）和意愿值选课。意愿值选课中，学生一般每学期获得100个意愿值，学习年限4年以上的每学期150个，按投放数量和课容量确定结果；选课失败或期间退课，意愿值退还。教学班一般不足15人不开班，需改选其他课程。
## 正选、补退选与退课
正选可能安排在学期初、学期末或假期；补退选一般在开学初。具体轮次和开放课程以学校信息门户的选课通知为准。退课一般在开课三周内办理；超过时间因疾病等特殊原因需退课的，需本人申请，经任课教师、学院审核和教务处审批。非补选期间原则上不补选。
## 免听与免修
因时间冲突、已掌握内容或平均学分绩点3.5及以上，可申请免听，每学期最多两门，需在开课前两周申请；思政课、军事理论、体育及实验实习等实践环节不能免听。免听仍需完成作业和考核。退役学生可申请军训、体育免修；非英语专业学生可凭四六级、雅思、托福等成绩申请部分英语课程免修，具体认定以当年选课说明为准。
