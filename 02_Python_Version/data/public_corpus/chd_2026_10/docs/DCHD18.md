# 长安大学校园网故障报修
## 报修方式
学生和教职工可拨打校园网服务电话 82334701，也可以在信网处的智能运维平台自助创建报修工单，运维人员接单处理。电话远程指导解决不了的问题会登记后安排上门。
## 常见问题
路由器死机：如果电脑直连网口能上网，先把路由器断电十分钟再重启，或重置路由器。忘记网络账号密码：拨打 82334701 核实本人信息后查询，或携带校园卡到运维中心办公室办理。
## 办公地点
南校区：北院教学主楼一楼西侧信网处网络运维服务中心。北校区：修远教学楼三区3101信网处办公室。网络报修全天受理，其他业务请在工作日咨询。
